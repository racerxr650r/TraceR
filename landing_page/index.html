Features

Everything you need for traceable software

From safety-critical certification to everyday quality assurance, TraceR keeps your requirements, design, and tests in perfect sync.

📄

Single Source of Truth

One doc/Project.xml drives every specification document. Edit in one place; all generated documents update automatically.

🔗

Full Traceability Matrix

Forward and reverse links from SDD through HLRs and LLRs all the way to individual tests — always up to date.

🧩

VS Code Extension

Structural Project Spec tree, lint diagnostics, coverage status-bar, code lenses, schema-driven form panels, and an AI chat participant — all inside your editor.

🐍

Python CLI Toolchain

Lint, render, and edit Project.xml from the command line or a Makefile with no VS Code required.

🤖

AI Assistance

@projectspec chat participant with grounded slash commands, plus deterministic + AI-assisted three-way merge resolution for Project.xml.

✅

Certified-Friendly

Designed for safety and certification environments. TraceR itself is built using TraceR — complete with SDP, SDD, HLRs, LLRs, STP, and Traceability Matrix.

How it works

From one file to a full specification stack

TraceR follows a simple, repeatable workflow that keeps every artefact consistent with your source of truth.

  1. Author Project.xml

    Define your project's metadata, high-level requirements, low-level requirements, design, and tests in a single structured XML file — or let the VS Code form panels do it for you.

  2. Lint and validate

    The built-in linter and XSD schema catch broken trace references, missing fields, and structural errors before any documents are generated.

  3. Render documents

    Run make render (or let the extension do it on save) to produce SDD, HLRs, LLRs, STP, and the Traceability Matrix as Markdown files.

  4. Review and iterate

    Use code lenses to jump between requirements and tests, check coverage stats in the status bar, and ask @projectspec for AI-guided suggestions.

Getting started

Up and running in minutes

Choose the integration that fits your workflow — VS Code extension for the full authoring experience, or the Python CLI for headless and CI environments.

VS Code Extension (recommended)

Download the .vsix from the latest GitHub Release and install it with one command. The extension bundles the Python sidecar — no separate Python install needed. 

code --install-extension vscode-project-xml-*.vsix
Latest release ↗

Python CLI Toolchain

Clone the repo and bootstrap the virtual environment with Make. Use lint, render, and edit commands standalone or from CI. 

git clone https://github.com/racerxr650r/TraceR.git
cd TraceR
make -C tools bootstrap
