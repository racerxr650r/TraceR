# Add a High-Level Requirement

HLRs answer *what the project must do*. Each one carries a stable
`HLR-NNN` id and a short name; the body is markdown.

Run **Project Spec: Add High-Level Requirement…**. You'll pick the
section it belongs to; the next free id is allocated for you.

The new HLR appears in the Project Spec tree under its section, and
its body becomes editable in the form panel.
