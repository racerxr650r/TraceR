# Add a Low-Level Requirement

LLRs decompose an HLR into something an engineer can implement.
Each one lives under a `<function>` and carries an `LLR-XXX-NN`
id plus markdown body.

Run **Project Spec: Add Low-Level Requirement…**. Pick the function;
the form provides the next free id and a `traces` editor for
referencing the HLR(s) the LLR realises.
