# Add an SDD Module

SDD modules describe the *how*: the path the module lives at, its
purpose, responsibilities, key data structures and algorithm
sketches.

Run **Project Spec: Add SDD Module…** to scaffold a new
`<sdd>/<modules>/<module>` entry. The form derives directly from
the XSD's `ui:form` hints — adding new fields to `SddModule` in
`tools/project.xsd` surfaces them here automatically.
